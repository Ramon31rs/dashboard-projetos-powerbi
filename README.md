# dashboard-projetos-powerbi



\# Dashboard de Acompanhamento de Projetos — Power BI



Projeto de análise de dados simulando o acompanhamento de projetos de 

fabricação por fornecedor, com foco em tratamento de dados e criação 

de KPIs visuais.



\## Tecnologias utilizadas

\- MySQL (extração e modelagem de dados)

\- Power BI Desktop (tratamento, modelagem e visualização)

\- DAX (criação de medidas)



\## Processo

1\. Criação de banco de dados relacional com tabelas de projetos e fornecedores

2\. Consulta SQL com INNER JOIN para extração dos dados

3\. Tratamento de dados no Power Query (padronização de texto, remoção de 

&#x20;  duplicatas, tratamento de valores nulos)

4\. Criação de medidas DAX (% de projetos no prazo, total de atrasados)

5\. Construção de dashboard interativo com cartões de KPI, gráficos e 

&#x20;  segmentador de dados
